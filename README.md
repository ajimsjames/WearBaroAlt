# WearBaroAlt

WearBaroAlt is a standalone barometric altimeter and atmospheric pressure monitoring client for Wear OS.

## Features
- Real-time ambient barometric pressure mapping in hPa\n- Altitude calculations based on standard pressure readings\n- AMOLED dark mode display with round bezel contours

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.
